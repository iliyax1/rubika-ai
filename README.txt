Rubika AI - نسخه اولیه
=========================
این نسخه یک رابط چت موبایل‌پسند و آماده برای اتصال به بک‌اند است.

برای پاسخ واقعی:
1) یک بک‌اند امن بسازید.
2) کلید API مدل هوش مصنوعی را فقط روی سرور نگه دارید.
3) فرم چت را به endpoint بک‌اند مثل /api/chat وصل کنید.
4) برای روبیکا، وبهوک/بات روبیکا را به همان بک‌اند متصل کنید.

نکته: کلید API را داخل HTML یا JavaScript سمت کاربر قرار ندهید.
